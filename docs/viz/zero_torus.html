Zeta Zero Torus

Each zero ½ + iγ of the Riemann zeta function becomes a point with angles θp = γ log p mod 2π. The critical line turns into a spiral of irrational slope that never closes, and the zeros are marked points along it. The surface tint is Landau’s prediction: zeros avoid angle 0 for every prime. Further down, each panel adds a layer to the same torus, ending with what a finite window of Weil’s quadratic form can certify.

How the layers fit

Every panel on this page is a layer on the same torus. Each button sets the 3-D view to show that layer.

  1. The arithmetic lives in the angles. For every prime p, zeros avoid θp = 0 and gather near π. Landau’s formula predicts this without assuming RH, and the surface tint shows it.

  2. The Euler product is a function on the torus. Its truncation is smallest where every angle is π, and the zeros sit where it is small.

  3. Leaving the critical line means leaving the surface. An off-line pair sits at tube radius q±δ, one point on each side of the seam. It changes Weil’s quadratic form by only about δ².

  4. Where such a pair can hide depends on the angles. Dense zeros near θ ≈ π hide it best, so the hiding map follows Landau’s tint.

  5. A window sees a fixed part of this picture. A test function supported in [−a, a] reads prime powers up to x = e2a, and its certified upper bound on λ charges each zero by height alone. The charge is the same at every angle and the same on or off the surface.

  6. A different L-function has a different torus. Borromean primes are pairwise unlinked from p₁ and p₂ but linked as a triple. On the torus of the Rédei L-function, reached by three quadratic steps, they invert Landau’s bias.

Layer 5 explains why the upper bound also holds for the Davenport–Heilbronn function. It has a functional equation and a zero count of the same form and satisfies the same kind of bound, yet it has zeros off the line. A positive lower bound for every window would imply RH, so it has to use something Davenport–Heilbronn lacks. The Euler product is the natural candidate, and on this torus it appears as the angle structure of layers 1, 2 and 4.

Euler product test

Fk(γ) = log |Πp ≤ pk (1 − p−½−iγ)−1| is a function on the torus, smallest where every angle is π. Along the spiral it averages exactly 0 (Jensen’s formula). Landau predicts the zeros sit lower, by Δk = A·Σ log p·log(1 − 1/p), and that the gap widens as primes are added.

The window minimum

Weil’s criterion turns RH into positivity of a quadratic form. Restrict the test functions to a window of length log x and the form has a smallest eigenvalue λ, which falls very fast as the window grows. An off-line pair like the one in the 3-D view changes the form by only about δ², so the size of λ is what a window can resolve. For ζ and for L(s, χ) of conductor q the natural scale is c = 2πx/q.

Borromean primes

Three primes can be pairwise unlinked yet linked as a triple, like the Borromean rings. For primes p₁, p₂ ≡ 1 mod 4 with (p₁/p₂) = 1, Rédei’s symbol [p₁, p₂, p] = ±1 is the arithmetic version of Milnor’s triple linking number (Morishita). It lives in a degree-8 field R with Galois group D₄ and in that field’s 2-dimensional L-function L(s, ρ). The coefficient of L(s, ρ) at p is 0 when p is linked to p₁ or p₂. When p is not linked to either, the coefficient is 2·[p₁, p₂, p].

Landau’s formula reads that coefficient from the zeros. On the torus of L(s, ρ), the zeros avoid θp = 0 when the coefficient is +2 and gather there when it is −2. The chart reads it for every prime below 1000, from the zeros of L(s, ρ) for (p₁, p₂) = (5, 29) up to height 1000.
